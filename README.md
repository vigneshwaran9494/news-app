# News App

A React Native news application built with Expo that displays top headlines and allows you to explore news articles.

## Demo

https://raw.githubusercontent.com/vigneshwaran9494/news-app/main/demo/news_app_demo.mp4

## Features

- View top headlines from selected news sources
- Search and explore news articles
- Select and manage news sources
- Dark mode support
- Pull to refresh

## Getting Started

### Prerequisites

- Node.js installed
- Expo CLI (install with `npm install -g expo-cli`)

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Run on your preferred platform:
   - **iOS**: `npm run ios`
   - **Android**: `npm run android`
   - **Web**: `npm run web`

## Project Structure

- `app/` - Main application screens and routing
- `components/` - Reusable UI components
- `data/` - API integration and state management
- `constants/` - App constants and configuration
- `hooks/` - Custom React hooks
- `utils/` - Utility functions

## Tech Stack

- React Native
- Expo
- Redux Toolkit
- TypeScript
- Expo Router
